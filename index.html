Java Edition

Version 26.3 (dernière version)

  1. Ouvre le launcher Minecraft Java.
  2. Lance le jeu en version 26.3.
  3. Va dans Multijoueur → Ajouter un serveur.
  4. Entre l'adresse :
play.laconfreriefr.com

Port par défaut : 25565

📱

Bedrock Edition

Pour MCPE / Console / Pc

  1. Ouvre Minecraft Bedrock.
  2. Va dans l'onglet Serveurs.
  3. Ajoute un serveur manuellement.
  4. Entre l'adresse et le port :
play.laconfreriefr.com:25566

Port : 25566

🔐 Connexion au serveur

Au premier lancement, enregistre-toi avec :

/register <mot de passe> <mot de passe>

Si tu as un compte acheté (officiel), fais :

/premium

Comme ça, tu n'auras plus besoin de taper le mot de passe.

Tu as oublié ton mot de passe ? Ajoute un email :

/email add <ton email> <ton email>

📜 Règles du serveur

  • Respecte les autres.
  • Pas de triche.
  • Amuse-toi.

❓ FAQ / Problèmes courants

Je ne trouve pas le serveur

Vérifie que tu utilises la bonne édition (Java ou Bedrock) et le bon port. Bedrock utilise le port 25566.

« Invalid session » ou connexion refusée

Si tu es en compte cracké, vérifie que le launcher est bien configuré pour un pseudo sans espaces ni caractères spéciaux.

J'ai oublié mon mot de passe

Si tu as ajouté un email avec /email add, tu peux le récupérer. Sinon, demande à l'admin.

Je joue sur Bedrock et je ne vois pas le serveur

Ajoute le serveur manuellement avec l'adresse play.laconfreriefr.com et le port 25566.
