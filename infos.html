🧩 Plugins installés

  • AuthMe — connexion avec mot de passe
  • LuckPerms — gestion des permissions
  • WorldEdit — édition du monde (admin)
  • WorldGuard — protection des zones
  • Geyser-Spigot — permet aux joueurs Bedrock de rejoindre
  • floodgate — support des comptes Bedrock
  • LPCF — chat personnalisé
  • CommandAPI — API pour les commandes
  • packetevents — gestion des paquets

💾 Sauvegardes & Uptime

Le serveur est hébergé 24h/24. Des sauvegardes automatiques sont faites régulièrement pour protéger vos constructions.

Si le serveur est hors ligne, c'est probablement pour une mise à jour ou une maintenance rapide.
